# 游戏工作区约定

- `src` 保存本游戏的引擎外 C# 源码，`Runtime` 是各库项目唯一源码目录。
- Domain 只依赖 BCL；可独立计算的规则用显式输入/输出，不修改调用方输入。
- Application 依赖 Domain 及按需选用的公共框架，负责状态提交、流程和外部效果；不引用引擎或服务端实现。
- 引擎工程只保存必要的场景、资源、表现及接线，外部产物由工作区命令更新，不能手改生成的 DLL。
- Server 负责进程/主机配置和基础设施，客户端与服务端可以共享契约和规则，但不共享进程状态。
- 框架不能依赖本游戏；玩法、账号、支付等具体业务先在本区域实现，不直接塞入公共框架。
- 修改前先读目标项目 README。生命周期在宿主创建线程执行；后台工作通过 Dispatcher 回到宿主线程，不在宿主线程同步等待异步工作。
- 对依赖/构建入口的变化同步维护工作区清单与说明；不要提交引擎缓存和 .NET 构建输出。
