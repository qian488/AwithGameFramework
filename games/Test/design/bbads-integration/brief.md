# Test 接入 BBads 与美术资产流水线

将 `E:/projects/BBads` 的现有战斗原型迁入 `games/Test/client/Unity`，作为 Test 中可单独进入、重跑和验收的演示。以源项目行为为基线，完成背包摆放、触发召唤、时间轴刷怪与道具、单位交战、基地状态和源场景已有的结束条件。用同一场景检验美术资源的导入、压缩、分辨率档位、打图集和实际合批。

[工单规格](board.json)

## 源工程与迁移基线

- BBads 的只读基线为 `72f9e87ca38f00e8e78142e8f8ad12b7e2e2d366`，Unity **6000.3.6f1**。启用的场景是 `Assets/Scenes/SampleScene.unity`，包含背包网格、战斗 HUD、波次轨道和 2D 全局灯。它使用 URP **17.3.0**、Input System **1.18.0**、uGUI **2.0.0**，`BBads.Runtime` 引用 Spine 4.2 和 TextMesh Pro。配置入口在 `Assets/Resources/Csv`，包括 `unit`、`attack_profile`、`item`、`encounter`、`item_spawn` 和 `summon_position`。
- Test 的目标基线为 **2022.3.16f1**，已使用 Input System **1.7.0**、uGUI **1.0.0** 和 TMP **3.0.6**。先盘点实际可达的包、材质、Shader Graph、Renderer2D、插件和按字符串加载的资源。用最小场景验证序列化、组件和包版本。全局渲染管线的选择以 BBads 画面和 Test 原有场景的回归结果为依据。Unity 6.3 用于获取源工程的运行基线，本机当前已找到的验证编辑器是 2022.3.16f1。
- 场景迁移到 `Assets/BBads/Scenes/BBadsBattle.unity`。源文件和 `.meta` 以配对方式迁移。针对 GUID 冲突或组件重建维护旧 GUID、旧 fileID、目标对象和全部引用的映射。检查场景依赖与代码中的动态键，迁入实际使用的素材。为动态资源、图集与配置使用 BBads 的独立资源键，覆盖 `Resources.Load(All)` 这类静态依赖无法发现的路径。两套客户端的设置和包按实际依赖逐项合并。差异记录应能解释每项转换及其验证方式。

## 美术资产处理

1. **可维护的导入规则。** 从迁入素材选择代表组，记录源 GUID、引用、原始尺寸、透明度、导入格式、最大尺寸、mipmap、Read/Write、滤镜、像素单位、Pivot、九宫格和切片。按 UI 图标、独立背景、世界 Sprite、Spine 页、数字与字体制定可审查规则与按资源例外。支持预览变更、应用和重复执行，生成规则及资源依赖报告。
2. **压缩与分辨率。** 建立两套可独立构建和强制选择的资源档位。以 Windows 高档和 Android 移动档作为初始验收建议。目标格式由实际平台支持、透明边缘和画质基线决定。移动档的背景和图标优先评估更小的像素尺寸，保留 UI 逻辑尺寸、锚点、Pivot 和九宫格。若同一平台需要按设备选择资源，通过互斥的档位分组和稳定资源键选择，记录实际取用的资源及回退行为。平台导入覆盖用于生成各平台的纹理，设备档位选择在 Player 中另行验证。
3. **图集与合批。** 按一起显示或一起加载的界面和战斗资源分组。优先处理背包/HUD 的重复图标和世界中的共享 Sprite。对大背景单独记录加载依赖。Spine 使用自带骨骼图集、页面和材质，按资源组测纹理占用和材质切换。针对 Canvas/排序层、遮罩、材质例外与文字记录拆批原因。在目标画面通过 Frame Debugger 或可用的渲染计数验证实际批次变化。
4. **前后对照。** 在同一平台、同一局面、同一相机和 Canvas 配置下记录包体或资源组体积、导入格式、纹理驻留估算或实测内存、批次数/提交次数和截图。比较实际加载而非只看磁盘图片尺寸。代表组中的背包/HUD 至少给出一组可重复测到的合批改善，低档至少给出一组纹理占用降低的证据。全局量化目标在基线采集后确定。

从 trunk 吸收按场景和界面分组、区分图集子图与独立 Sprite 的加载标识、显示对象换图时取消旧请求，以及用真实发布依赖和运行内存验证变体的做法。参考 `E:/projects/trunk/Program/Client/GameApp/Resource/ResourceManager.Sprite.cs`、`ClientPublish/Bin/Assets/Res/UITex/Atlas` 和 `tools/LANGUAGE_IMAGE_USAGE.md`。按 Test 的原生图集或已有资源接口实现这些做法。
