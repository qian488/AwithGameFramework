# Test PvP 协议

`tools/game.ps1 protocol -Name Test` 从共享 schema 生成消息类型。AWRT 负责二进制封装、连接内序号和心跳。加入请求携带模式、房号和玩家名。服务端分配席位、对局 ID、会话编号和恢复凭据。输入携带对局、会话、序号和目标步，快照头中的确认号记录最后消费的输入。

- Rain Pass 的 `frames` 包含房间头、按席位排序的玩家标识和输入帧。每帧包含步号、两份量化输入和服务端状态哈希。`frameReplay` 使用同一帧类型补发历史。客户端演算生成角色状态、飞行中的箭和表现事件。
- BBads 的 `snapshot` 包含房间头、双方权威状态和表现事件。重连从最新状态继续。
