# Test 雨夜远征

从营地选择装备和首段路线，先打盐风堤或余烬铸造厂。首段结束进入休整菜单，选择补箭或清除架势压力后可关闭游戏。重开后继续杉林决战。首次通关某条分支奖励一枚印记，解锁一套武备消耗一枚。离线记录待提交成绩，按当局内容版本、分支和装备档分榜。两段战报分别回看。

子 Agent 从同一 Git 基线在独立 worktree 实现工单。每张工单提供写入范围、前置依赖和独立检查。主 Agent 汇集交付，并在后台引擎验证正式入口。实体手柄、声音和战斗观感留给人工体验。

主路径使用同一档案完成 v1 第一段，保存休整点，安装 v2 后离线重开，以保留的 v1 进度完成决战。再重开并连接成绩服务，查看分组排名。隔离测试应能定位越界文件，并识别两个工单交付同一文件的冲突。
