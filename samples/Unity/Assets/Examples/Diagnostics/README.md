# Unity 诊断示例

本目录保留三个 Unity `MonoBehaviour` 脚本：`FrameworkTestRunner`、`PerformanceTester` 和 `ExampleUsage`，分别作为功能检查、性能测试和使用示例的入口。它们当前只有类定义与 TODO，尚不执行检查。

可交互的演示脚本位于 [Assets/Test](../../Test)。无需 Unity 的自动化测试位于仓库根 [tests](../../../../../tests)，完整验证从仓库根运行 [tools/verify.ps1](../../../../../tools/verify.ps1)。
